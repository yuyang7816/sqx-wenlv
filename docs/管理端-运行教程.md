# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `lvyou-admin` 文件夹。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「省钱兄文旅启动成功...」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 Node.js 18 或更高：https://nodejs.org/

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18` 或 `v20`，以及 `10.x`。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

用记事本打开 `lvyou-admin/.env.development`。整个文件应是这一行：

```text
VITE_API_BASE_URL=http://127.0.0.1:9186/sqx_fast/
```

如果还是一个 `https://` 开头的网址，改成上面这一行，保存。`.env.production` 也改成同一行。

这个文件名以小数点开头。资源管理器里如果看不到，到「查看」里打开「文件扩展名」。用记事本打开时选「所有文件」。

改完这个文件之后，如果网站已经在运行，要先停掉再启动，修改才会生效。

## 第 2 步：安装依赖

在 `lvyou-admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `lvyou-admin` 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址，一般是：

```text
http://localhost:5173/
```

用浏览器打开这个地址。如果自动跳到登录页，地址是：

http://localhost:5173/login

登录页上应能看到一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要一直开着。

## 怎样算成功

使用导入库里的演示账号登录。用户名是 `admin`，密码是 `123456`。登录成功后进入「数据统计」，左侧能看到菜单。景点、酒店、订单等列表是空的，需要在后台自己添加。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开 PowerShell。

**`npm ERR!` 且提示需要 Node 18**  
`node -v` 低于 18。到 nodejs.org 安装 18 或 20 的长期支持版，盖过旧版本后再执行 `npm install`。

**浏览器打不开 localhost:5173**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `.env.development` 不是 `http://127.0.0.1:9186/sqx_fast/`。改完后在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 5173 is in use`**  
5173 已被占用。关掉之前的管理端窗口再启动。
