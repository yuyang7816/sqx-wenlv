# 服务端运行教程

按顺序做。做完一步，看到文中写的成功标志，再做下一步。

服务端是三个端里要第一个启动的。代码在 `lvyou-server` 文件夹。数据库不用自己建表，项目里已经带了一份导出文件：`lvyou-server/sql/wenlv.sql`。

## 开始之前要准备什么

在自己的 Windows 电脑上安装下面四个软件。安装时勾选「添加到 PATH」或「Add to PATH」。

| 软件 | 用什么版本 | 怎样确认已经装好 |
|---|---|---|
| JDK | 1.8（也叫 Java 8） | 开始菜单打开「命令提示符」或 PowerShell，输入 `java -version`，能看到 `1.8.0` |
| Maven | 3.6 或更高 | 输入 `mvn -v`，能看到 `Apache Maven 3` |
| MySQL | 8.0 或更高 | 开始菜单里能找到「MySQL 8.0 Command Line Client」 |
| Redis | 5.0 或更高 | 双击 `redis-server.exe` 后窗口不关闭，另开窗口输入 `redis-cli ping`，回复 `PONG` |

Java 不要装成 11 或 17。装错版本时，先卸掉，再装 1.8。下载可用 Adoptium 的 Temurin 8：https://adoptium.net/temurin/releases/?version=8

MySQL 安装过程中会让你给 `root` 设一个密码。把这个密码记在纸上。`application-dev.yml` 里写的本地密码是 `root`。如果你安装时设的不是这个密码，后面改配置文件时要改成你自己的密码。

Redis 可以到 https://github.com/tporadowski/redis/releases 下载 Windows 版压缩包，解压后双击 `redis-server.exe`。这个黑色窗口要一直开着，关掉就等于 Redis 停了。

## 第 1 步：新建空数据库

这份 SQL 文件里是表和数据，它不会自己创建名叫 `wenlv` 的库。要先建库，再导入。

1. 打开「MySQL 8.0 Command Line Client」。
2. 输入你的 root 密码，回车。看到 `mysql>` 才算连上。
3. 把下面这一整行复制进去，回车：

```sql
CREATE DATABASE IF NOT EXISTS wenlv DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
```

4. 再输入：

```sql
SHOW DATABASES;
```

列表里有 `wenlv` 就成功了。输入 `exit` 退出。

如果提示 `Access denied`，是密码错了，用安装 MySQL 时设的那个密码重来。

## 第 2 步：导入项目里的数据库文件

文件位置（相对整个项目文件夹）：

`lvyou-server/sql/wenlv.sql`

这是 2026 年 10 月 30 日导出的完整库，库名是 `wenlv`，里面已经有表、菜单和业务数据。导入会覆盖同名的表，所以请导入到上一步新建的空库，不要导入到别的业务库。

在项目根目录（能同时看到 `lvyou-server`、`lvyou-admin`、`lvyou-uniapp` 的那一层）打开 PowerShell，执行。把 `-proot` 里的 `root` 换成你的 MySQL root 密码：

```powershell
$mysql = "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
& $mysql -uroot -proot --default-character-set=utf8mb4 wenlv -e "source $($PWD.Path -replace '\\','/')/lvyou-server/sql/wenlv.sql"
```

执行时窗口会停一会儿。结束时没有 `ERROR`，再执行下面这句，能看到很多表名，就说明导入成功：

```powershell
& $mysql -uroot -proot --default-character-set=utf8mb4 -e "USE wenlv; SHOW TABLES;"
```

如果提示找不到 `mysql.exe`，到 `C:\Program Files\MySQL\` 下面找到实际的 `mysql.exe`，把上面第一行的路径换成你的路径。

用 Navicat 也可以：连接到本机 MySQL，双击打开 `wenlv`，菜单选「运行 SQL 文件」，选中 `lvyou-server/sql/wenlv.sql`，点开始。底部显示成功即可。

## 第 3 步：让程序连接你自己的 MySQL

打开这个文件：

`lvyou-server/sqx-application/src/main/resources/application-dev.yml`

找到这三行：

```yaml
url: jdbc:mysql://127.0.0.1:3306/wenlv
username: root
password: root
```

地址保持 `127.0.0.1`，库名保持 `wenlv`。`password` 改成你的 MySQL root 密码。再打开 `application-prod.yml`，库名同样写成 `wenlv`，`用户名` 和 `密码` 改成和上面一样。当前默认使用的就是 prod 这份配置。

两份文件都保存。

Redis 不用改。开发配置使用本机 `127.0.0.1` 的 `6379` 端口，没有密码。请确认 `redis-server.exe` 的窗口还开着。

## 第 4 步：启动服务端

在 `lvyou-server` 文件夹里打开 PowerShell，执行：

```powershell
mvn clean package -DskipTests
cd sqx-application
mvn spring-boot:run
```

第一次会下载很多依赖，可能要 10 到 30 分钟，窗口要一直开着。看到这行字才算启动成功：

```text
省钱兄文旅启动成功...
```

不要关闭这个窗口。关闭后服务端就停了。

用 IDEA 也可以：用 IDEA 打开 `lvyou-server`（选有 `pom.xml` 的那一层），等右下角 Maven 导入结束，打开 `sqx-application/src/main/java/com/sqx/SqxApplication.java`，点左侧绿色三角。控制台同样要出现「省钱兄文旅启动成功...」。Project SDK 选 1.8。

## 怎样算成功

浏览器打开：

http://127.0.0.1:9186/sqx_fast/doc.html

能看到接口文档页面。如果这份配置把文档关掉了，只要启动日志里有「省钱兄文旅启动成功...」，并且接下来管理端能打开登录页上的验证码图片，也算服务端已经就绪。

后台登录账号是导入库里的演示账号：用户名 `admin`，密码 `123456`。短信、微信、支付宝、地图这些密钥需要自己到对应官网申请，再填进管理端。申请入口写在 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**`java` 不是内部或外部命令，或版本不是 1.8**  
Java 没装好，或装成了更高版本。安装 Temurin 8，关掉 PowerShell 再打开，重新执行 `java -version`。

**`Access denied for user 'root'`**  
MySQL 密码和 yml 里的 `password` 不一致。把 `application-dev.yml` 和 `application-prod.yml` 里的密码改成你安装 MySQL 时设的密码，导入命令里的 `-p` 后面也改成同一个密码。

**`Unknown database 'wenlv'`**  
第 1 步的建库没有成功。回到命令行把 `CREATE DATABASE` 再执行一次。

**`redis` 连接失败，或启动卡在 Redis**  
`redis-server.exe` 没有开，或端口不是 6379。先打开 Redis 窗口，再启动服务端。

**`Port 9186 was already in use`**  
9186 端口已经被占用。把之前开着的服务端窗口关掉，或在任务管理器里结束对应的 Java 进程，然后再启动。

**导入 SQL 时中文变问号**  
命令里要带 `--default-character-set=utf8mb4`。用 Navicat 时，运行 SQL 文件的编码选 UTF-8。
