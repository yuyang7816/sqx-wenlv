# 用户端运行教程

按顺序做。这是给手机和网页用的应用，用 HBuilderX 打开 `lvyou-uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `lvyou-server/sql/wenlv.sql` 并启动服务端。首页上的景点、酒店来自这个库。服务端没启动时，页面也许能打开，但列表是空的，登录会失败。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `lvyou-uniapp/common/domain.js`。里面应是：

```javascript
export const USER_H5_ORIGIN = 'http://127.0.0.1:9186';
```

再打开 `lvyou-uniapp/common/config.js`，找到这一行：

```javascript
const USE_LOCAL_SERVER = false;
```

把 `false` 改成 `true`，变成：

```javascript
const USE_LOCAL_SERVER = true;
```

只改这一个单词。`true` 表示接口使用本机 `http://127.0.0.1:9186`。保存文件。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `lvyou-uniapp` 这个文件夹。不要选它的上一级（那一层还有 `lvyou-server`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`manifest.json`、`common`。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址一般是 http://localhost:5588/ 。如果控制台里写的是别的端口，用控制台里的地址。
4. 打开后顶部标题是「首页」，能看到搜索框。库里有内容时，下面会列出推荐。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里已经写了一个小程序 AppID。那是原项目的号码。你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把 `manifest.json` 里 `mp-weixin` → `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

## 怎样算成功

首页能打开。按键盘 `F12`，点「网络」或 Network，再按一次浏览器的刷新。列表里的请求地址应是 `127.0.0.1:9186`。出现别的网站域名，说明第 1 步没有保存，或改完后没有重新点「运行到浏览器」。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `lvyou-uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不是 `lvyou-uniapp`。

**首页能开，但没有数据，登录失败**  
服务端没有启动，或 `USE_LOCAL_SERVER` 仍是 `false` 且 `domain.js` 不是 `http://127.0.0.1:9186`。先看服务端窗口是否还有「省钱兄文旅启动成功...」，再改第 1 步，然后重新运行到浏览器。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。
