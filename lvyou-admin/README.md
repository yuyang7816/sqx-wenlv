# 省钱兄架构管理后台

基于 Vue 3 + Vite + Element Plus 的管理端，对接 `lvyou-server`（`/sqx_fast`）。

> 库名/账号/端口以 `lvyou-server/sqx-application/src/main/resources/application-dev.yml` 为唯一真相源。

## 启动

```bash
npm install
npm run dev
```

开发 API（`.env.development`）：`http://localhost:9135/sqx_fast/`
